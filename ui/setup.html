Step 1 of 5

Language

Choose the display language for the web UI. You can change it any time in Settings.

Serial Connection

Select the RS485 serial port the heat pump HAT is connected to.

Registers to monitor can be enabled from the Registers tab after setup. The pump model is auto-detected from the first RS485 frame if left on auto-detect.

MQTT Broker

Connect to an MQTT broker to publish register values. Required for Home Assistant integration. You can skip this and configure it later in Settings.

Enable MQTT
Enable Home Assistant MQTT Discovery

Please enter a host address.

Authentication

Optionally protect the web UI with HTTP Basic Auth. Anyone on your local network can access the UI unless you enable this.

Enable authentication

Enter a username and password to continue.

Review & Finish

Check your settings and click Finish to save and start the bridge.

Registers to monitor and all other settings are available in the main UI after setup.
